# Crypto Portfolio Dashboard

Một dự án web mô phỏng bảng điều khiển quản lý danh mục crypto theo phong cách sản phẩm thực tế.

## Chức năng hiện có

- Hiển thị tổng giá trị danh mục
- Theo dõi nhiều tài sản như BTC, ETH, SOL và USDT
- Tính biến động mô phỏng trong 24 giờ
- Hiển thị lãi hoặc lỗ trong ngày
- Bảng tài sản chi tiết với số lượng, giá và giá trị
- Danh sách theo dõi coin
- Lịch sử giao dịch mô phỏng
- Phần nhận xét nhanh để tóm tắt trạng thái danh mục

## Công nghệ sử dụng

- HTML
- CSS
- JavaScript

## Cấu trúc thư mục

```text
crypto-portfolio-dashboard/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Cách chạy

1. Tải mã nguồn về máy
2. Mở file `index.html` bằng trình duyệt

## Hướng phát triển tiếp

- Kết nối ví thật
- Lấy dữ liệu giá thật từ giao diện lập trình ứng dụng
- Thêm biểu đồ tài sản theo thời gian
- Thêm đăng nhập và lưu danh mục lâu dài
- Hỗ trợ nhiều ví và nhiều danh mục khác nhau
